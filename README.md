# 🎓 Student Record Management System

A beginner-friendly **Python project** to manage student records using CSV and JSON file storage.

## 🚀 Features

- ➕ **Create:** Add new student records.
- 📋 **Read:** View all student records and search by student ID.
- ✏️ **Update:** Modify existing student information.
- 🗑️ **Delete:** Remove student records.
- 📁 **File Handling:** Store and retrieve data using CSV and JSON.
- 🛡️ **Exception Handling:** Handle invalid inputs and file errors.
- ✅ **Input Validation:** Validate student IDs, ages, names, courses, and marks.
- 📊 **Filter Records:** Display students who have passed.

## 🛠️ Technologies Used

- Python 3
- CSV
- JSON
- File Handling
- Exception Handling
- Functions and Lambda
- List Comprehensions

## ⚙️ How to Run

1. Install Python 3 from https://www.python.org/downloads/
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run the following command:

```bash
python student_manager.py
```

5. Choose your preferred storage format: `csv` or `json`.
6. Use the interactive menu to manage student records.
